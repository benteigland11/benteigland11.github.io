LSM6DSV320XTR Breakout Board

MPU 6050 form factor breakout for STMicro’s dual range IMU, ±16G and ±320G accelerometers plus a ±4000 dps gyro, built for Bethel Rocket Club and the open source community. Flown MyVersion2 board

Hardware · KiCad Featured

Altitude Prediction Module

Version 2 flight computer, 4 layer PCB with STM32L412 MCU, BMP388 barometric pressure sensor, and MPU 6050 IMU for fused altitude estimation. USB micro programming, expansion headers, and dedicated analog and digital power domains for clean sensor reads in a rocket payload bay. Manufactured via JLCPCB and flown on a rocket.

MCU
STM32L412KBTx, Cortex M4, 128 KB flash, 80 MHz
Sensors
BMP388 barometer and MPU 6050 6 axis IMU
Fabrication & flight
JLCPCB assembly · flown on a rocket launch

Cartograph

Local first reusable code registry for AI agents. Widgets bundle code, tests, examples, and metadata; nothing enters the library until native language validation actually runs. Search, install, validate, and checkin across projects so agents reuse proven work instead of re-deriving the same logic from scratch.

Core idea
Proof, not storage. Validated widgets as durable agent memory.
Stack
CLI, cloud registry, MCP server, Claude and Codex plugins
Languages
Python, Nim, JS/TS, OpenSCAD, SystemVerilog, Terraform, and more

Waymark Terminal

GPU rendered terminal emulator written end to end in Nim, assembled from 47 reusable Cartograph widgets. Pure Nim VT parser, screen buffer, UTF-8 decoder, glyph atlas, and platform neutral PTY host. The terminal is the showcase; the widgets are the point.
